# 고르다 (Goreuda)

> 좋은 마음을 위한, 바르고 고른 선택.

받는 사람과 상황에 맞는 **선물 인사이트**를 먼저 보여주고, 추천 상품의 **판매처별 가격을 비교**해 구매 사이트로 연결해 주는 선물 고민 도우미 웹사이트입니다.

**사이트 바로가기**: https://ezhye0n.github.io/goreuda/15_goreuda_main.html

숙명여자대학교 웹프로그래밍 중간과제 15팀 결과물로, JavaScript 없이 HTML과 CSS만으로 제작했습니다.

---

## 어떤 서비스인가요?

선물을 고를 때 가장 어려운 것은 "무엇을 줄지" 정하는 일입니다. 기존 선물 서비스는 상품 목록과 결제 중심이라, 어떤 종류의 선물이 받는 사람에게 맞는지는 알려주지 않습니다.

고르다는 상품을 직접 팔지 않습니다. 대신 다음 세 가지를 돕습니다.

- **선물 인사이트 (GIFT GAP)**: "많이 주는 선물"과 "실제로 받고 싶은 선물"의 차이, 피하면 좋은 선물을 보여줍니다.
- **판매처 가격 비교**: 고른 상품을 판매처별 가격, 배송, 혜택으로 비교하고 해당 판매 사이트로 연결합니다.
- **찜 후보 비교**: 찜한 선물을 한 표에 나란히 놓고 비교하며, 고르다의 추천을 함께 보여줍니다.

> 추천 결과는 "20대 여성 친구 / 생일 / 3만원대" 예시 시나리오를 기준으로 구현했으며, 별점과 인사이트 수치는 예시 데이터입니다.

## 페이지 구성

| 페이지 | 파일 | 주요 내용 |
|---|---|---|
| 메인 | `15_goreuda_main.html` | 배너, 상황별 카테고리, GIFT GAP 미리보기, 이번 주 셀렉션 |
| 조건 선택 | `15_goreuda_select.html` | 받는 사람, 선물하는 날, 예산, 취향을 선택 버튼으로 고르기 |
| 추천 결과 | `15_goreuda_result.html` | 추천 선물 종류, 많이 주는 선물 vs 받고 싶은 선물, 추천 상품 |
| 상품 상세 | `15_goreuda_detail.html` | 상품 정보, 추천 이유, 선물 인사이트, 받은 사람 후기 |
| 판매처 가격 비교 | `15_goreuda_compare.html` | 판매처 3곳의 가격, 배송, 혜택 비교와 최저가 강조 |
| 상품 탐색 | `15_goreuda_explore.html` | 카테고리, 가격대 필터와 상품 카드 목록 |
| 찜한 선물 비교 | `15_goreuda_wishlist.html` | 찜한 상품 3개, 고르다의 추천, 비교표 |
| 선물 인사이트 리포트 | `15_goreuda_report.html` | 관계별, 나이대별, 상황별 선물 리포트 |

### 이동 흐름

1. **추천**: 메인 → 조건 선택 → 추천 결과 → 상품 상세 → 판매처 가격 비교 → 외부 판매처
2. **탐색**: 상품 탐색 또는 인사이트 리포트 → 상품 상세 → 판매처 가격 비교
3. **결정**: 상품 카드에서 찜 → 헤더의 하트 → 찜한 선물 비교 → 판매처 가격 비교

## 주요 기능 (HTML, CSS만 사용)

- **hover로 나타나는 카드 버튼**: 상품 사진에 마우스를 올렸을 때만 가격 비교 버튼이 나타나 카드 목록이 깔끔합니다.
- **찜 하트**: 하트를 누르면 색칠된 상태로 유지되고, 다시 누르면 취소됩니다. 숨긴 체크박스와 `label`, `:checked`로 구현했습니다.
- **안내 말풍선**: 글자 없는 아이콘에 마우스를 올리면 기능 이름이 나타납니다.
- **선택 버튼**: 조건 선택과 필터는 라디오 버튼을 알약 모양으로 꾸며 입력 없이 고릅니다.
- **GIFT GAP 막대그래프**: 많이 주는 선물과 받고 싶은 선물을 색과 막대 길이로 비교합니다.
- **고정 헤더와 최상단 가기**: 헤더는 스크롤해도 위에 붙어 있고, 푸터의 "최상단 가기"로 맨 위로 이동합니다.

## 접근성

- `header`, `nav`, `main`, `section`, `footer` 등 의미에 맞는 태그 사용
- 모든 이미지에 대체 텍스트(`alt`), 아이콘 버튼에 `title`과 말풍선
- 페이지 맨 위 "본문 바로가기" 링크, 입력 요소와 `label` 연결
- 찜 하트는 키보드(Tab, Space)로도 사용 가능
